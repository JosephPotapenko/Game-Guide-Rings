ARTIFACT GUIDE BUILDER

Open index.html in a modern browser.

Features:
- Five artifact slots in the established left/right/left/right/left layout.
- Blank page title area.
- Drag/drop or choose artifact images.
- If an image filename contains an artifact name from all_items_names_and_descriptions.txt or artifacts.json, the name and description are filled automatically.
- Search the artifact list and choose an entry manually.
- Edit any name or description.
- Save/load a draft in the same browser.
- Export the completed page as a PNG.

The template is the supplied 1024x1536 parchment image.
